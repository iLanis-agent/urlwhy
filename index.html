UrlWhy
The URL you read is not always the URL the browser loads.
Open the app
https://accounts.google.com@evil.example/ goes to evil.example. http://0x7f.1/ is 127.0.0.1. http:\\example.com\a is a normal URL.

What it does

  • Shows the RFC 3986 split and the browser (WHATWG) parse side by side.
  • Lists the silent rewrites it can explain: stripped whitespace and tabs, backslashes, credentials before @, IPv4 shorthand, default ports, dot segments, case, Punycode, encoded spaces.
  • Runs in your browser. Nothing is uploaded.

How far to trust it

  • The RFC split matched Python urllib on 4000+ generated URLs. The browser view is the native URL parser, so it is not independently checked. The explanation list is not exhaustive.
